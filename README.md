## 🗂️ File Structure

| Sheet | Description |
|-------|-------------|
| 📋 **Data** | Raw transaction data — 366 rows × 8 columns (Jan 2021 – Jan 2022) |
| 📊 **Dashboard** | Interactive visual dashboard with charts & slicers |
| 🖥️ **Product** | Product-level analysis sheet |
| 👤 **Salesman** | Salesman-level performance sheet |
| 🔢 **PivotTable** | Pre-built pivot summaries (monthly, regional, product, salesman) |

---

## 🧾 Dataset Columns

| Column | Type | Description | Example |
|--------|------|-------------|---------|
| `S No` | Number | Serial number / row ID | 1, 2, 3 … |
| `Date` | Date | Transaction date | 01-Jan-2021 |
| `Salesman` | Text | Name of salesperson | Siddhu, Rohit Das |
| `Region` | Text | Sales region | East · West · North · South |
| `Item` | Text | Product sold | Printer · Monitor · Mouse |
| `Qty` | Number | Quantity sold per transaction | 2 – 7 units |
| `Price` | Number | Unit price (₹) | ₹190 – ₹2,100 |
| `Amount` | Number | Total value = Qty × Price (₹) | ₹380 – ₹14,700 |

## 🚀 Getting Started

1. **Download** `Dashboard.xlsx`
2. Open in **Microsoft Excel 2016+** or **Google Sheets**
3. Navigate to the **Dashboard** sheet for the visual overview
4. Use **slicers** to filter by Salesman, Region, Item, or Month
5. Add new rows to the **Data** sheet and hit `Data → Refresh All` to update all pivots and charts

---

## ⚙️ Requirements

- Microsoft Excel 2016+ *(recommended — full slicer & chart support)*
- Google Sheets *(basic pivot support; slicers may not render)*
- No macros or external add-ins required

---

## 📝 Notes

- All monetary values are in **Indian Rupees (₹)**
- `Amount` is a derived field: `Qty × Price`
- Date range covers **1 Jan 2021 to 1 Jan 2022** — exactly 366 daily transactions
- All Pivot Tables are pre-built and refresh automatically on data changes
- Slicers on the Dashboard sheet are linked to all charts and pivot tables
